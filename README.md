# KnowFlow AI
## AI Knowledge & Customer Support Platform

Backend-only AI project built with FastAPI, LangChain, and LangGraph.

### Initial development scope
- No database in the initial version.
- No MCP in the initial version.
- Temporary in-memory storage where needed.
- Local file storage for uploaded documents.
- Mock LLM provider initially; real model integration will be added later.
- Retrieval will begin with an in-memory approach and can later be extended with Qdrant.

### Planned modules
- Document upload and processing
- Text extraction and chunking
- Knowledge retrieval
- Grounded AI answer generation
- LangGraph support agent
- Support ticket escalation
- Conversation/session handling
